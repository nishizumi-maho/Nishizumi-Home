Nishizumi-Control

A hotkey assisted control manager for iRacing driver adjustments (brake bias, TC, ABS, etc.), with multi device inputs, an on screen HUD overlay, presets, and optional speech/voice features. (STABLE RELEASE)

Nishizumi-fuel

A lightweight Tkinter overlay that reads iRacing telemetry and shows fuel per lap, remaining laps, and stint planning, including deltas vs a target and auto refuel detection. (STABLE RELEASE)

View on GitHub

Nishizumi-Calculator

“Drive Fair Share Calculator”, a multilingual static web calculator for team events that computes equal share and minimum fair share laps per driver and can estimate time per driver using average lap time. (STABLE RELEASE)

View on GitHub

Nishizumi-Tools

A small bundle of pit operation helpers: Fuel Helper (warnings around fuel/autofuel and pit timing) and Turbo Pit (UI/CLI for sending pit command broadcasts, with toggles and auto clear options). (WIP)

Nishizumi-IBT

An experimental Tkinter overlay that compares your live telemetry to a reference lap extracted from a local .ibt file, showing throttle/brake/speed traces and cue points to benchmark driving. (WIP)

Nishizumi-Share

An experimental privacy focused setup/file sharing system using Tor hidden services (.onion) for anonymous team file sharing and syncing, aiming to avoid exposing IPs and relying on optional controls like rate limiting and scanning. (WIP)
